# RGB to YUV

Ứng dụng web minh họa chuyển đổi không gian màu **RGB sang YUV**, phục vụ học tập và thực hành xử lý ảnh/video số.

## Cấu trúc

```text
rgb-to-yuv/
├── index.html
├── script.js
├── style.css
└── README.md
```

## Thành phần

- `index.html`: giao diện.
- `script.js`: xử lý chuyển đổi RGB → YUV và tương tác.
- `style.css`: định dạng giao diện.

## Mục đích

Giúp quan sát và kiểm tra kết quả chuyển đổi giữa các thành phần màu RGB và YUV trực tiếp trên trình duyệt.

> Mã nguồn hiện có được giữ nguyên; chỉ chuẩn hóa README.
