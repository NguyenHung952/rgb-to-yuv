# 📖 Giới thiệu

**RGB to YUV Converter** là một web tool hỗ trợ chuyển đổi giá trị màu từ hệ màu **RGB** sang **YUV** thường được sử dụng trong:

- 📺 Xử lý ảnh và video
- 🎥 Truyền hình số
- 📡 Viễn thông đa phương tiện
- 💻 Computer Vision
- 🖼 Digital Image Processing

Người dùng có thể:

- Nhập giá trị RGB thủ công
- Chuyển đổi từng pixel
- Nhập ma trận NxN để xử lý hàng loạt
- Hiển thị kết quả chuyển đổi theo thời gian thực
